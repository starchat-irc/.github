# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use "Report a vulnerability" on the Security tab of the affected repository. The report is only visible to the maintainers.

Include what you found, how to reproduce it and which version or commit is affected. You will get an answer within a week.

## Supported versions

Until the first stable release, fixes go into `main` and the latest release only.

## Scope

This covers the code in the `starchat-irc` repositories. Problems with a specific IRC network or its discovery file belong to that network's operators. Entries in `servers/servers.json` that point to a malicious network can be reported the same way.

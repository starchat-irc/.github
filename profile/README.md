## StarChat

An open source IRCv3 client for the web and the desktop. Any IRC network works with it, and networks can offer extra services through a discovery file.

- [starchat](https://github.com/starchat-irc/starchat): client and list of networks
- [getstarchat.net](https://github.com/starchat-irc/getstarchat.net): website

Work in progress, first release planned for December 2026.
